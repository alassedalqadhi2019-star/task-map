🔑 ربط الموقع بخرائط جوجل

عشان تشتغل الزحمة المباشرة والطرق المحدّثة، يحتاج الموقع مفتاح Google Maps خاص فيك. تسويه مرة وحدة (حوالي 10 دقايق):

  1. افتح Google Cloud Console بحساب جوجل، وسوِّ مشروع جديد باسم مثلاً my-task-map.
  2. من Billing اربط بطاقة. جوجل تعطي حد مجاني شهري لكل خدمة، واستخدامك الشخصي غالباً ما يوصل له.
  3. فعّل الخدمات الثلاث من المكتبة: Maps JavaScript API و Routes API و Places API (New).
  4. من Credentials اضغط Create credentials ← API key، وبعدين من API restrictions اختار الخدمات الثلاث بس.
  5. (للأمان المالي) من صفحة Routes API ← Quotas حط حد يومي مثلاً 150 طلب، كذا مستحيل تتعدى المجاني.
  6. انسخ المفتاح والصقه هنا:
إعدادات متقدمة (اختياري)
المفتاح ينحفظ في متصفحك على جهازك بس، وما يطلع لأي مكان غير خرائط جوجل.
